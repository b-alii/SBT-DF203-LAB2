# SBT-DF203-LAB2
## Lab Description

This laboratory exercise focuses on **HTTP traffic analysis using Wireshark**, with emphasis on identifying and recovering an image embedded in a webpage. A local Apache web server is used to host an HTML page containing an image, while Wireshark/tshark is used to capture and analyze the resulting HTTP traffic.

The lab covers evidence preparation, SHA-256 hashing, HTTP request and response analysis, TCP segmentation and reassembly, and extraction of the embedded image from the captured traffic. The recovered image is then compared with the original source image using file information and SHA-256 hashes to verify its integrity.

The exercise also includes basic evidence and chain-of-custody documentation and a comparison between browser-generated HTTP traffic and traffic generated using `curl`.

## Lab Objectives

By the end of this laboratory, the learner should be able to:

1. Prepare a structured environment for digital forensic network analysis.
2. Configure and use **Apache2, curl, Wireshark, tshark, and ImageMagick**.
3. Capture HTTP traffic generated when a webpage and its embedded image are requested.
4. Identify and analyze HTTP requests and responses using Wireshark/tshark.
5. Demonstrate that separate HTTP objects, including the HTML page and image, were requested.
6. Analyze TCP segmentation and reassembly associated with an HTTP image transfer.
7. Export an embedded image from captured HTTP traffic.
8. Calculate and compare SHA-256 hashes to verify evidence and recovered-image integrity.
9. Document relevant forensic findings, including requests, responses, timestamps, content type, content length, and TCP information.
10. Compare HTTP traffic generated by a browser with traffic generated using `curl`.
